ASTRA CLIENT MOD (Minecraft 1.21.11, Fabric) + GitHub build

Lefordítás a GitHubon (nem kell semmit telepíteni a gépedre):
1) github.com -> New repository (pl. "astra-client-mod"), Public vagy Private.
2) "uploading an existing file" -> húzd be ennek a mappának a TARTALMÁT
   (.github mappa, src mappa, README.txt) -> Commit changes.
3) Actions fül -> "Build Astra Client mod" -> Run workflow (zöld gomb).
4) Ha kész (zöld pipa): kattints a futásra -> Artifacts -> astra-client-1.21.11 -> letöltés.
5) A zipből a jar fájlt másold a launcher projekt "bundled-mods" mappájába
   (név: astra-client-1.21.11.jar).
Ha piros X lesz: nyisd meg a futást, másold ki a hibaüzenetet és küldd el.
